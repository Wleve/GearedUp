# React + Vite Project

This project was bootstrapped with [Vite](https://vitejs.dev/) and uses React (JavaScript).

## Getting Started

### Run the development server

```
npm run dev
```

### Build for production

```
npm run build
```

### Preview production build

```
npm run preview
```

## Migrating your HTML/CSS/JS
- Move your static HTML into React components (e.g., `Contact.html` → `Contact.jsx`).
- Place your CSS in the `src` folder or import it into components as needed.
- Update navigation to use React Router if you want SPA navigation.
